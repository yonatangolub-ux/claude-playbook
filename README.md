# שיטת העבודה עם Claude Code

איך בונים מערכת עם Claude Code מההתחלה עד הסוף: סשנים קצרים, תוכנית לפני קוד, והליבה נבנית מחיכוכים אמיתיים ולא מדמיון.

## מה יש כאן

| קובץ | מה בו |
|---|---|
| [METHOD.md](METHOD.md) | השיטה המלאה: 7 עקרונות, 7 שלבים, תבנית סשן, 3 רמות בדיקה, מלכודות |
| [STORY.md](STORY.md) | סיפור לדוגמה: דניאל בונה את "מסלול", צעד אחרי צעד |
| [CHECKLIST.md](CHECKLIST.md) | צ'קליסט לפרויקט חדש |
| [LESSONS.md](LESSONS.md) | מה למדנו מפרויקטים אמיתיים שנבנו בשיטה |
| [GITHUB.md](GITHUB.md) | Git ו-GitHub בלי קוד: ריפו, קומיט, ענף, push, Pages ועוד |
| [template/](template/) | קבצי הפתיחה של כל פרויקט חדש |

## איך מתחילים פרויקט חדש

1. **לפני המחשב:** הבעיה במשפט אחד, מבחן הצלחה של כן/לא, ורשימת "לא עכשיו" (פרטים ב-[CHECKLIST.md](CHECKLIST.md)).
2. **ריפו חדש ב-GitHub** לפרויקט, עם שם שמתאר אותו.
3. **סשן ראשון עם Claude** על הריפו החדש, במצב תכנון:
   > "תעתיק את הקבצים מתיקיית template/ בריפו claude-playbook לשורש של הריפו הזה. ואז תראיין אותי לפי METHOD.md ותמלא את SPEC.md. בלי קוד עדיין."

מכאן ממשיכים לפי [METHOD.md](METHOD.md), שלב 2.

## הקבצים שכל פרויקט מקבל

| קובץ | התפקיד |
|---|---|
| `CLAUDE.md` | החוקים. Claude קורא אותו בתחילת כל סשן. קצר בכוונה |
| `SPEC.md` | הבעיה, מבחן ההצלחה, "לא עכשיו", ומה בגרסה 1 |
| `NOTES.md` | איפה עצרנו, ושורת "הבא:" אחת |
| `frictions.md` | רשימת המשימות האמיתית: מה הציק בשימוש |
| `IDEAS.md` | רעיונות שמחכים, ולא נבנים בינתיים |

## משפרים את השיטה

השיטה עצמה עובדת לפי אותם חוקים: כשמשהו בה מציק בפרויקט אמיתי, רושמים את זה ב-[LESSONS.md](LESSONS.md), ומעדכנים את METHOD.md או את template/ רק אחרי שהלקח חזר או הוכח.
